# Money Time homepage concepts

Three homepage redesign concepts for [Money Time with Ebonie Dion, Esq.](https://www.longevitybc.com/), built with the scroll-craft skill. All copy, prices, and credentials come from the live site. Nothing is invented.

| Concept | Folder | Idea |
|---|---|---|
| A. The Cover | `ledger/` | A business-magazine cover with Ebonie in front of the masthead. The cover lines fly into the margin and become the chapter menu. |
| B. The Application | `application/` | The homepage is a grant application that fills itself in. It has a live budget worksheet, and your business name gets stamped onto an approval seal. |
| C. The Hourglass | `hourglass/` | Split screen: guessing vs. Money Time. The hourglass on the divider drains, flips, and Money Time takes the page. |

## View

- **Quickest:** open any file in `dist/`. Each concept is one self-contained HTML file.
- **From source:** run `python3 -m http.server 4500` in this folder, then open `http://localhost:4500/ledger/` (or `application/`, `hourglass/`).
